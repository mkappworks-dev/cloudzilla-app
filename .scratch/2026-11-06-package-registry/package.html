Cloudzilla

Self-hosted git forge. One binary, PostgreSQL, no git on the host.

Run it

docker run -p 8080:8080 -e CZ_DATABASE_DSN=… localhost:8080/mkappworks/cloudzilla-server:v0.4.1

See docs/deployment.md for volumes and the bootstrap admin.
