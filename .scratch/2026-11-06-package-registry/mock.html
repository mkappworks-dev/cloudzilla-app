Push a container image or upload a file with a personal access token that has packages:write.

Container image

Use the token as the password. An image whose org.opencontainers.image.source label points here is linked to this repository.

echo "$CZ_TOKEN" | docker login localhost:8080 \
  -u malith --password-stdin
docker tag cloudzilla localhost:8080/mkappworks/cloudzilla:v0.1.0
docker push localhost:8080/mkappworks/cloudzilla:v0.1.0

Generic file

One PUT per file. The URL names the package, its version and the file.

curl -X PUT \
  -H "Authorization: Bearer $CZ_TOKEN" \
  --upload-file dist/cz-cli_linux_amd64.tar.gz \
  localhost:8080/api/packages/mkappworks/cloudzilla/cz-cli/0.1.0/cz-cli_linux_amd64.tar.gz

Pulling from a private repository needs packages:read. Create a token in Settings → Access tokens
