What changed from v1
Row: dot · checkbox · type icon · title + muted action · avatar of who triggered it · date.
Hover (or keyboard focus) swaps the date for ✓ Done and 🔕 Unsubscribe, as on GitHub. Try it: hover a row, tick checkboxes.
Ticking any checkbox turns the header into "N selected · Done · Unsubscribe".

Open points to decide
1. Unsubscribe means stop watching that repository (removes your watch). We have no per-thread subscriptions, so it affects every future notification from that repo. The tooltip says so. Hidden on the transfer row (no watch involved) and on rows for a repo you don't watch.
2. Done = today's "mark as read" (rows stay in the inbox, shown greyed, and move to the Read filter). No separate archive state.
3. Avatar is the actor's profile picture, falling back to initials (existing components.Avatar).
