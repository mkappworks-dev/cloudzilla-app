Commit a YAML file under .cloudzilla/workflows/ on the default branch. The next push runs it:

# .cloudzilla/workflows/ci.yml
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: host
    steps:
      - name: Test
        run: go test ./...

Statuses that external CI posts still show under Commit statuses. Pipelines can be turned off in Settings → CI/CD.
