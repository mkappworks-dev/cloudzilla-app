# Profile README Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a user's profile README on their `/{username}` page when they own a public repo named after their username that has a `README.md` at the root of its default branch.
**Architecture:** Zero-migration. `CodeService` gains a `GetProfileReadme` method that reads the blob using the existing `GetRawBlob` helper and passes the result through `markdown.Render`; `PageUser` in `page_handler.go` calls it after loading repos and passes the resulting `template.HTML` to `UserData`; the `user.html` template renders it above the repos list.
**Tech Stack:** Go 1.23, chi, sqlx, PostgreSQL, Templ, HTMX, Alpine.js, Tailwind CSS

---

## Task 1 — Add `GetProfileReadme` to CodeService

- [ ] Edit `internal/service/code_service.go`.

  Add the following method after `GetRawBlob`. It silently returns empty `template.HTML` for all error conditions (repo missing, README absent, repo private, empty repo):

```go
// GetProfileReadme reads README.md from the root of the given repo's default
// branch and renders it as HTML. Returns empty template.HTML (not an error)
// when the repo, commit, or README does not exist.
func (s *CodeService) GetProfileReadme(ownerName, repoName, defaultBranch string) (template.HTML, error) {
    raw, err := s.GetRawBlob(ownerName, repoName, defaultBranch, "README.md")
    if err != nil {
        return template.HTML(""), nil
    }
    return markdown.Render(string(raw)), nil
}
```

  Also ensure the import `"html/template"` is present at the top of `code_service.go`. Check the existing imports — if `html/template` is not already imported (it is not needed by current methods), add it. The `markdown` package is imported in `page_handler.go` but not yet in `code_service.go`, so you must also add `"github.com/mkappworks/cloudzilla/internal/markdown"` to the import block of `code_service.go`.

**Test command:** `go build ./internal/service/...`

## Task 4 — Populate ProfileReadme in PageUser

- [ ] Edit `internal/handler/page_handler.go`.

  In `PageUser`, after the block that builds `repos` and before the `h.render` call, add logic to find the special profile repo and fetch the README:

```go
var profileReadme template.HTML
for _, repo := range repos {
    if repo.Name == user.Username && !repo.Private {
        if html, err := h.Services.Code.GetProfileReadme(user.Username, user.Username, repo.DefaultBranch); err == nil {
            profileReadme = html
        }
        break
    }
}
```

  Then pass `ProfileReadme: profileReadme` into the `UserData` literal in the `h.render` call:

```go
h.render(w, "user", UserData{
    BasePage:      basePage(r, h.Services),
    User:          *user,
    Repos:         repos,
    ProfileReadme: profileReadme,
})
```

  The import `"github.com/mkappworks/cloudzilla/internal/markdown"` is already present in `page_handler.go` but `GetProfileReadme` is called on the service so no additional import is needed here.
