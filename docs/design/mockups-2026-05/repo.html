Cloudzilla

A self-hosted Git forge built in Go with Templ and HTMX. Issues, pull requests, code review, and CI integration — without the bloat.

● v0.2.0 Go 1.23+ BSL 1.1

Quickstart

git clone https://cloudzilla.dev/mkappworks/cloudzilla.git
cd cloudzilla
make setup-tailwind
make migrate
make dev

Open http://localhost:8080 and you'll land on the setup wizard.

Architecture

  • Backend: Go 1.23+, chi router, sqlx, go-git, cobra CLI
  • Frontend: Templ (type-safe Go HTML), HTMX for partial updates, Tailwind CSS
  • DB: PostgreSQL
  • Git Transport: HTTP smart protocol + SSH server (both pure-Go, no git binary required)

Project layers

Strict separation: Stores → Services → Handlers → View. Handlers never call stores directly.
