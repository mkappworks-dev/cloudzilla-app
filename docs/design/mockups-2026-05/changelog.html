Cloudzilla · Changelog

What's shipped

Notable changes, additions, and fixes. Subscribe via RSS.

  1. v0.18.0

    May 10, 2026 feature

    Dependency graph + advanced code search land. Repos now show a navigable graph of imports and a global search index that ranks by symbol.

    • Add repository dependency graph for Go and TypeScript projects.
    • Global search now supports symbol: and path: qualifiers.
    • Pull request page shows a tree of changed files alongside the diff.

  2. v0.17.2

    Apr 22, 2026 fix

    SSH transport now correctly handles connection re-use under high concurrency. Resolves intermittent remote hung up unexpectedly errors during CI fan-out.

  3. v0.17.0

    Apr 5, 2026 feature breaking

    Breaking: the cz_token cookie is now SameSite=Lax by default. If you embed Cloudzilla in an iframe on another origin you'll need to flip auth.cookie_samesite back to none.

    • Add discussions feature with categories, answered-by tracking, and category-level pinning.
    • Project boards now support cross-repo cards.

  4. v0.16.0

    Mar 12, 2026 feature

    TOTP two-factor authentication. Recovery codes are downloadable from Account settings → Security.
