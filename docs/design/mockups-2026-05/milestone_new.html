About milestones

A milestone groups issues and pull requests toward a shared goal — a release or a sprint — and tracks how many are closed.

Good to know

  • ·Leave the due date blank for an open-ended milestone.
  • ·Assign this milestone from any issue or pull request once it exists.
  • ·Closed milestones stay searchable with milestone: filters.
