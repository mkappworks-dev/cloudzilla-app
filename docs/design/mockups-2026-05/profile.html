👋 Hey, I'm Malith

I build small, focused developer tools — mostly in Go. Right now I'm head-down on Cloudzilla, a self-hosted Git forge designed for teams who want GitHub's UX without the GitHub footprint.

Outside of that, I write a fair amount of Templ, TypeScript, and bash — and occasionally rust when the situation calls for it.
