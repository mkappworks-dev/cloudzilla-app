Release notes

Dependency graph

This release ships the dependency graph for go.mod and package.json manifests, giving every repository a parsed view of its direct and transitive dependencies.

What's new

  • Parse and render the dependency graph for Go modules from go.mod / go.sum.
  • Parse and render npm dependencies from package.json, including dev dependencies.
  • Surface direct vs. transitive dependencies with version constraints.
  • Add the auto-publish workflow powered by release-please — merged release PRs now tag and publish automatically.
  • Release notes are generated from Conventional Commits since the previous tag.

Upgrade notes

No migrations are required. The dependency graph is computed on first view and cached per commit.
