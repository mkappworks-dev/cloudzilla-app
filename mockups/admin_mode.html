Admin mode

Outside admin mode you are a normal user on every repository and organization. Admin mode lets this browser open and change any of them for a limited time.

  • It needs your password or second factor again.
  • It applies to this browser only, and ends when you leave it, sign out or change your password.
  • Every change made because of it is written to the audit log.
  • It never applies to API tokens, git or SSH.

You are in admin mode until 15:32 UTC.
