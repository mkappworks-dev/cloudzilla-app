Setup on Mac

A one-time walkthrough for getting a Cloudzilla development environment running on macOS.

1. PostgreSQL

Cloudzilla stores everything in PostgreSQL. Install and start it with Homebrew, then create the database:

brew install postgresql@16
brew services start postgresql@16
createdb cloudzilla

2. Tailwind CLI

The CSS is compiled by the standalone Tailwind CLI. The Makefile downloads it for you:

make setup-tailwind

3. Run the server

Point Cloudzilla at your database, apply migrations, and start the dev server — this also runs the Tailwind watcher:

export CZ_DATABASE_DSN="postgres://localhost/cloudzilla?sslmode=disable"
make migrate
make dev

The app is now serving on http://localhost:8080.
