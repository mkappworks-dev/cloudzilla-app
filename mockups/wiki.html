Welcome to the Cloudzilla wiki

This wiki holds project-wide documentation that doesn't fit in the README — design notes, runbooks, contributor onboarding, and the longer-form architecture decisions.

Pick a topic

The sidebar on the left lists every wiki page. The most commonly-visited entry points:

  • Architecture — the strict Stores → Services → Handlers layering, plus how Templ and HTMX fit together.
  • Contributing — branch naming, commit conventions, and how to run the test suite locally.
  • Setup-on-mac — the one-time PostgreSQL and Tailwind CLI setup steps.

Editing pages

Anyone with write access can edit pages. Click Edit in the page header to open the Markdown editor. Each save writes a commit to the wiki's bare repo — you can review history in the project's audit log.
