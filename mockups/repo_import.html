What gets imported

Every branch and tag, with full history. The new repository's default branch matches the source's.

Keeping it in sync

A mirror follows force pushes and deleted branches too. Issues and wikis stay local. You can stop mirroring later from the repository's settings.

Not imported

  • Issues, pull requests, wikis, and releases.
  • Git LFS files: only their pointer files come across.
  • Later changes to the source, unless you keep it in sync.
