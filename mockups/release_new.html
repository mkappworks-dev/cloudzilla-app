About releases

A release packages a Git tag with notes and downloadable assets — the cuttable points in your project's history.

Good to know

  • The tag is created on the target branch's latest commit if it doesn't already exist.
  • Mark a pre-release when the build isn't production-ready.
  • Saving as a draft keeps the release private and notifies no one until you publish.
