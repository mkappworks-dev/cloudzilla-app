README.md

Cloudzilla

A self-hosted Git forge built in Go with Templ and HTMX. Issues, pull requests, code review, and CI integration, without the bloat.

Quickstart

git clone https://cloudzilla.dev/mkappworks/cloudzilla.git
cd cloudzilla
make setup-tailwind
make migrate
make dev

Open http://localhost:8080 and you'll land on the setup wizard.

Architecture

  • Backend: Go, chi router, sqlx, go-git, cobra CLI
  • Frontend: Templ, HTMX for partial updates, Alpine.js, Tailwind CSS
  • DB: PostgreSQL
  • Git transport: HTTP smart protocol and SSH server, both pure Go with no git binary required

Contributing

See CONTRIBUTING.md for the development workflow. PRs welcome; check the roadmap in docs/ROADMAP.md for in-flight work.
